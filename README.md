# retro-maze

A maze-chase arcade game for the browser: eat every dot, dodge four ghosts with distinct
personalities, turn the tables with an energizer. Original maze, characters, art and sound;
faithful arcade-style rules, without the original bugs.

**Status:** design study (brick 0). No playable build yet.

- Game design: [docs/design/game-design-document.md](docs/design/game-design-document.md)
- Decisions: [docs/decisions/](docs/decisions/)
- Architecture (UML): [docs/architecture/](docs/architecture/README.md)
- Log: [PROJECT_LOG.md](PROJECT_LOG.md)

Planned stack: TypeScript (strict), native Canvas 2D, Vite.

`retro-maze` is a codename. This project is not affiliated with, nor endorsed by, any arcade
publisher; it uses no third-party name, sprite, sound or maze.
